# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |
| dev-master before 1.0 | No |

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/FLAIRUK/laravel-cities/security/advisories/new),
or email ijeffrouk@gmail.com.

You will get a reply within a week. Once a fix is released, the advisory is
published with credit to you, unless you would rather not be named.
